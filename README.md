# Gene Pool (мод с хищниками)

Симуляция эволюции «Gene Pool» Джеффри Вентреллы, переведённая на TypeScript.
Исходный код автора без изменений лежит в папке `GenePool Original`.

## Как запустить

Дважды щёлкните **`Запустить GenePool.bat`**. При первом запуске он установит
инструменты (нужен [Node.js](https://nodejs.org)), затем откроет игру в браузере.
Чтобы остановить игру, закройте чёрное окно.

Из командной строки то же самое:

```
npm install      (один раз)
npm run dev      (запуск, адрес http://localhost:5173)
npm run build    (проверка типов и сборка готовой версии в папку dist)
```

Открыть `index.html` двойным щелчком больше нельзя: браузер не загружает
модули с диска, а для будущей многопоточности нужен локальный сервер.

## Где что лежит

| Путь | Что это |
|---|---|
| `src/main.ts` | точка входа: подключает модули, запускает интерфейс и симуляцию |
| `src/simulation/` | сама симуляция: существа, гены, мозг, еда, главный цикл (`GenePool.ts`) |
| `src/simulation/Parameters.ts` | настройки — хищничество, экология, численность |
| `src/ui/` | панели, кнопки, график, сохранение и загрузка |
| `index.html`, `css/`, `images/` | страница и оформление |
| `tools/` | прогоны без браузера для проверки изменений по цифрам |

## Прогоны без браузера

```
node tools/headless.cjs --steps 20000 --every 1000 --seed 1
node tools/variant.cjs 60000 1 INITIAL_PREDATOR_FRACTION=0 BASAL_METABOLISM=0.00001
node tools/headless.cjs --root "GenePool Original" --steps 20000
```

Одинаковый `--seed` даёт одинаковый результат, поэтому две версии кода можно
сравнить честно. `variant.cjs` меняет любые настройки без правки файлов.
Результаты удобно сохранять в `tools/results/` (в git не попадает).
