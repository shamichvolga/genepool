  Технические решения принимает ИИ; спрашивать только про поведение и геймплей.

## Проект
Мод «Gene Pool» Джеффри Вентреллы: эволюция «свимботов» в 2D-бассейне.
Добавлено хищничество: уровень хищности 0..1 (гены 129–130, раньше ген 51), порог 0.6.
Оригинал автора без изменений лежит в `GenePool Original/`.

- Запуск: `Запустить GenePool.bat` или `npm run dev` (порт 5173).
- `npm run build` — проверка типов и сборка.
- Код: `src/simulation/` — симуляция, `src/ui/` — интерфейс,
  `src/main.ts` — точка входа. Все экспорты модулей кладутся на `window`,
  потому что кнопки в `index.html` вызывают функции через `onclick`.
- Настройки (хищничество, экология): `src/simulation/Parameters.ts`;
  среда — `Environment.ts` (карта) и `Ecology.ts` (формулы); гены экологии —
  `EcologyGenes.ts`; нейромозг — `NeuralBrain.ts`; размер мира — `World.ts`.

## Инструменты проверки (папка tools/, запуск через Node без браузера)
- `node tools/headless.cjs --steps N --every K --seed S` — прогон со статистикой
  (численность, хищники, растения, мясо, «виды»).
- `node tools/variant.cjs <шаги> <seed> NAME=value ...` — прогон с изменёнными константами.
- `node tools/bench.cjs <существ> [шагов] [seed] [папка]` — скорость и «отпечаток» состояния.
- `node tools/compare.cjs <папка другой копии> [шагов] [seed] [существ]` — пошаговое
  сравнение двух версий кода; находит первый шаг расхождения.
- `node tools/eco.cjs --seed S --steps N --every K [--flat 1] [--set "ИМЯ=знач,..."]` —
  прогон пула со средой: численность, клина θ~T, пищеварение~T, яркость~фон,
  экотипы, показатели мозга. `--flat 1` — контроль «без среды».
- `node tools/physics-timing.cjs`, `tools/profile-lines.cjs` — профилирование.
- `--root "GenePool Original"` у headless/bench — прогон оригинала автора для сравнения.
- Профиль: `node --cpu-prof --cpu-prof-dir=tools/prof ...` (длинные пути на Windows не работают).

**Метод:** любое изменение, которое не должно менять поведение, проверять через
`compare.cjs` против копии кода до изменения — состояние должно совпадать бит в бит.
Экологические изменения проверять прогонами на нескольких seed по 60 000+ шагов
и сравнивать с оригиналом автора.

## Текущая точка и приоритеты (2026-10-15)

Полная приоритизированная таблица задач, обоснований и способов реализации —
[docs/ТЗ_не_сделано.md](docs/ТЗ_не_сделано.md). Это основной список будущих работ;
не поддерживать параллельный, расходящийся перечень ниже.

### Зафиксированные решения

- Растительная еда одного типа; сезонность может менять рост и доступность той же пищи.
- Не прописывать генам и мозгу готовый ответ «этот признак для этого биома».
  Поведенческую стратегию оценивать по фактическому выживанию и потомству.
- Волнообразная численность сама по себе не означает провал.
- Размер и форма тела должны менять реальные преимущества и затраты; не давать
  заранее назначенный бонус крупным или толстым телам в конкретном климате.

### Текущее состояние, важное для следующих изменений

- Среда, сезоны, нейросеть, хищничество и автотомия уже реализованы.
  Однотипная растительная пища включена через TWO_PLANT_TYPES = false.
- Прямые температурные гены и климатический множитель пищи ещё используются;
  их заменять только после проверки новой физической/энергетической модели.
- LOCAL_PLANT_GROWTH и BASAL_METABOLISM выключены: прежние прогоны углубляли
  раннее вымирание. Включать их по отдельности и с измерениями.
- C12 добавляет нейросетевые сигналы и наследуемые выходы для выбора живой добычи
  или мяса по ожидаемой энергии и оценке времени погони; CSV отдельно считает выборы,
  дистанцию и ожидаемую награду по каждому типу. `eco.cjs` также записывает фактические
  пары по яркости и созревание потомков по трём диапазонам родительской разборчивости.
  Переключатель выключен по умолчанию, долгие сравнения не запускались.
- UI и headless-скрипты называют группировку по используемым генам генетическими
  кластерами; грубые морфологические корзины считаются отдельно. Ни то ни другое
  не определяет биологические виды. Старые сохранённые CSV могут ещё содержать
  прежнюю колонку `species`.
- Физика движения и восприятие уже распараллелены по worker threads.
  Главный цикл всё ещё координирует шаги; metronome.worker обслуживает тики
