# Концепция «Ось»: другое тело, другое движение, другая вода

Набросок другого Gene Pool: тела растут иначе, двигаются иначе, вода устроена по законам гидродинамики. Это документ, кода нет. Строить его можно только как **отдельный режим мира**: геном здесь читается по-другому, и старые существа в нём не оживут.

## 0. Что не так у Вентреллы (с точки зрения разнообразия)

| Сейчас | Чем мешает |
|---|---|
| Каждое звено машет своей синусоидой: `изгиб = A·sin(ωt + φ·номер)` | движение задано целиком, тело не «чувствует» воду и не подстраивается |
| Толчок = скорость звена поперёк × доля длины, **без деления на массу** | большое тело разгоняется так же легко, как маленькое; вдоль тела вода почти не тормозит |
| Вода одинакова для любого размера | у мелких и крупных одна и та же лучшая форма, только в другом масштабе |
| Тело — список звеньев с перечнем начало/конец | форма меняется рывками, симметрии и узоров почти нет |

Главная мысль новой модели: **физика должна сама давать разные лучшие формы для разных задач и размеров.** Тогда вместе с нишами (`docs/концепт_питание_аммиак.md`) монополии неоткуда взяться: нет тела, которое лучше везде.

## 1. Тело: ось и поля вдоль неё

Тело — ось длиной L от головы (s = 0) до хвоста (s = 1). Всё остальное задают несколько **гладких полей** вдоль s. Так устроены настоящие зародыши: градиенты веществ вдоль оси решают, где что вырастет.

### 1.1. Профиль ширины (ряд Фурье)

```
w(s) = W₀ · max( 0.15,  1 + a₁·cos(πs + b₁) + a₂·cos(2πs + b₂) + a₃·cos(3πs + b₃) )
```

Шесть чисел a, b дают все обычные силуэты:
- **веретено** (a₁ < 0): толстый в середине, острый с концов;
- **клин:** широкая голова, тонкий хвост;
- **песочные часы** (a₂ > 0): широкая голова и широкий хвост;
- **две «лопасти»** (a₃);
- **хвостовой плавник:** узкий стебель перед хвостом и расширение на конце.

Маленькая мутация чуть меняет силуэт, а не перескакивает к другому телу.

### 1.2. Членистость рождается, а не задаётся

Внутри зародыша два вещества, «включающее» и «гасящее» (схема Тьюринга). Они дают волну с собственной длиной λ. Звенья получаются там, где волна проходит через ноль:

```
число звеньев  n = round( L / λ )      (не больше MAX_PARTS)
граница звена k:  s_k = k / n
```

Гены — L и λ, а не «сколько звеньев». Удлинение тела само добавляет звенья, как у настоящих червей и многоножек. Тот же ген λ рисует **полосы окраски** точно по звеньям: у вида появляется узнаваемый рисунок.

### 1.3. Изгиб в покое (крючки и спирали)

```
κ(s) = κ₀ + κ₁·s          (угол между соседними звеньями в покое, градусы на единицу длины)
```

- κ₀ ≠ 0 — тело дугой;
- κ₁ ≠ 0 — изгиб нарастает к хвосту: крючок, спираль, улитка. Видимо, это и есть «growth turn phase acc» из версии для ПК.

Изогнутое тело плывёт по кругу или винтом, если мозг этого не исправляет. Это форма с ценой и с пользой: прочёсывает место вокруг себя.

### 1.4. Конечности: третье поле

```
a(s) = sin( 2π·m·s + χ )
конечность растёт в звене k, если a(s_k) > θ;   длина конечности = ℓ_л · (a(s_k) − θ) / (1 − θ)
```

- m — сколько «волн конечностей» вдоль тела, θ — порог (чем выше, тем реже и короче конечности), χ — сдвиг.
- Конечности всегда парные, слева и справа. Ген σ ∈ [0, 1] решает, как они машут: σ = 0 — по очереди (как у многоножки), σ = 1 — разом (как вёсла лодки, толчок рывками).
- **Ветки на ветках:** конечность — тоже ось со своими полями, но короче. Глубина 2. Это «secondary branching» из версии для ПК.

### 1.5. Размер — это бюджет яйца

Гены задают только **пропорции**. Размер взрослого тела ограничен энергией яйца E_я: материал тела = Σ ℓᵢ·wᵢ. Ген размера яйца — это обычная сделка «много мелких детей или мало крупных». Отдельного запрета «не больше N» нет, кроме технического предела `MAX_PARTS`.

## 2. Движение: генератор ритма вместо готовых синусоид

### 2.1. Цепочка связанных осцилляторов

У каждого звена есть «нервный узел» с фазой θᵢ. Соседи подтягивают друг друга (модель Курамото, так устроен спинной ритм у миноги):

```
dθᵢ/dt = ω·(1 + e·u_скор)
       + K·[ sin(θᵢ₋₁ − θᵢ − Δ) + sin(θᵢ₊₁ − θᵢ + Δ) ]
       + γ · Fₙ,ᵢ · cos θᵢ                     ← чувство воды
```

| Буква | Что это |
|---|---|
| ω | собственная частота (ген) |
| u_скор | усилие от мозга (как сейчас «effort») |
| K | насколько звенья держатся друг за друга (ген) |
| Δ | сдвиг фазы между соседями (ген): длина волны по телу |
| γ | чувство воды (ген): сила воды Fₙ на звене подгоняет ритм |

**Почему это важно.** Без чувства воды (γ = 0) всё как у Вентреллы: бегущая волна θᵢ = ωt − iΔ. С ним ритм **сам подстраивается под тело и воду**: длинное тело само замедляет волну, короткое ускоряет. Одни и те же гены на разных телах дают разные походки, и у мутаций формы меньше вредных «рассогласований» с движением. Эволюции проще пробовать новые тела.

### 2.2. Изгиб звена

```
βᵢ = A(sᵢ)·sin θᵢ  +  u_пов · R(sᵢ)  +  κ(sᵢ)·ℓᵢ
A(s) = A₀ · ( α + (1 − α)·s^p )
```

**Профиль размаха A(s)** — это классические способы плавания рыб:

| α, p | Способ | Кто так плавает |
|---|---|---|
| α ≈ 1 (машет всё тело) | угревидный | угорь, минога, мелкие черви |
| α ≈ 0,3, p ≈ 2 | скумбриевидный | большинство рыб |
| α ≈ 0, p ≈ 6 (машет только хвост) | тунцовый | быстрые крейсеры |

Поворот: мозг даёт u_пов от −1 до +1, тело сгибается по профилю R(s) (ген: изгибать голову, середину или хвост). Изгиб в покое κ добавляется сверху.

### 2.3. Рывок («C-старт»)

Третий выход мозга u_рыв. Тело на мгновение сгибается буквой C, потом резко распрямляется:

```
βᵢ += u_рыв · B · R_C(sᵢ) · пульс(t)        пульс: 6 шагов изгиб, 4 шага распрямление
```

Ген B — сила рывка. Так рыбы уходят от хищника и так атакует засадник. Рывок стоит много энергии (п. 3.3), поэтому не всем выгоден.

### 2.4. Конечности: гребля с «пером»

```
угол конечности  αⱼ = α₀ + A_л · sin( θ_корня + Δ_л )
в обратном ходе лопасть разворачивается ребром:  cₙ,эфф = cₙ · (1 − f)
```

Ген f («перо», 0…1) у настоящих животных — это лапа утки или весло. Без пера (f = 0) лапа гребёт туда и обратно впустую. С пером даёт чистый толчок даже без изгиба тела. Отсюда второй класс движения: **гребцы.** Они медленные, зато поворачивают на месте и умеют стоять.

## 3. Вода: настоящая гидродинамика (и разная для мелких и крупных)

### 3.1. Сила на звено (теория сопротивления + присоединённая масса)

Для звена i: середина движется со скоростью v, t — вдоль звена, n — поперёк, vₜ = v·t, vₙ = v·n.

```
Вязкая часть:     F_вяз = −ℓᵢ · ( cₜ·vₜ·t + cₙ·vₙ·n ),   cₙ = kₙ·ν,  cₜ = kₜ·ν,  kₙ/kₜ ≈ 2
Инерционная часть: F_ин = −mₐ,ᵢ · d(vₙ)/dt · n,         mₐ,ᵢ = ρ·π·wᵢ²/4 · ℓᵢ   (присоединённая масса)
```

- **Вязкая часть** (теория Грея — Хэнкока). Поперёк звена вода держит вдвое сильнее, чем вдоль, поэтому волна изгиба толкает вперёд. Сейчас этого «вдоль» нет, отсюда скольжение, которое вы заметили.
- **Инерционная часть** (теория Лайтхилла для удлинённых тел). Широкое звено, которое быстро машет, отталкивает массу воды. Поэтому широкий хвостовой плавник даёт тягу.

### 3.2. Размер сам меняет законы (число Рейнольдса)

Отношение инерционной части к вязкой растёт с размером и скоростью: Re = U·L / ν. Здесь ν — **вязкость бассейна**, одно число мира.

| | Мелкие (Re мало) | Крупные (Re велико) |
|---|---|---|
| вода | «мёд»: остановился — сразу встал | «вода»: можно скользить |
| лучшая форма | тонкое тело, волна по всему телу, много мелких конечностей (как реснички) | веретено, узкий стебель, широкий хвост |
| бесполезно | широкий плавник (тяги не даёт) | волна по всему телу (дорого) |

**Ось размера** превращается в ось формы. Мелкий и крупный не могут быть «тем же червём в другом масштабе». Это закон природы, а не правило «чтобы работало». Так устроен настоящий мир: бактерии, рачки и киты плавают по-разному.

### 3.3. Движение тела и честная цена

```
M·dU/dt = Σ Fᵢ          M = Σ ρ_т·ℓᵢ·wᵢ         (масса делит силу, сейчас не делит)
I·dΩ/dt = Σ rᵢ × Fᵢ

мощность мышц   P = Σ | τᵢ · dβᵢ/dt |            (сколько работы ушло на изгиб против воды)
предел мощности P ≤ P_max = p_м · Σ ℓᵢ·wᵢ       (мышц столько, сколько тела)
если требуется больше — ритм замедляется:  ω_эфф = ω · min(1, P_max / P)

трата энергии за шаг = k_б · M^(3/4)  +  P / η          (закон Клейбера; η ≈ 0,25 — КПД мышц)
```

Тонкое длинное звено не может махать сильно и часто, ему не хватит мышц. Широкий хвост даёт тягу, но дорого стоит. Всё это следует из одной формулы мощности, без отдельных запретов.

### 3.4. Рот

```
ширина рта  g = w(0) · g_рот        (g_рот — ген)
проглотить целиком можно еду (или жертву) шириной ≤ g; больше — только откусывать
```

Это «ограничение по рту» из настоящей экологии. Хищник с узкой головой ест только мелких, с широкой — крупных. Пищевая сеть сама делится по размеру.

## 4. Что, вероятно, получится

Из физики следуют давно известные сделки (Webb, 1984, о плавании рыб): **крейсерская скорость, рывок и манёвр мешают друг другу.** Широкое глубокое тело хорошо для рывка и плохо для экономного хода. Длинный хвост хорош для хода и плох для поворота. Ожидаемые типы тел:

| Тип | Гены | Где выигрывает |
|---|---|---|
| **Угорь** | длинный, узкий, α ≈ 1, малое Δ | мелкий размер, вязкая вода, проходы между стволами |
| **Крейсер** | веретено, узкий стебель, широкий хвост, большое p | крупный размер, открытая вода, далёкая разбросанная еда |
| **Гребец** | короткое тело, 2–4 пары лап, перо f ≈ 1 | чаща, плоды у стволов, точные повороты |
| **Засадник** | глубокое тело, большой B (рывок) | хищник: короткая атака из укрытия |
| **Пульсатор** | лапы у головы, σ = 1 (машут разом) | рывками, дёшево на месте; поедатель дрейфующих семян |
| **Винт** | κ₁ ≠ 0, волна поверх изгиба | плывёт спиралью, прочёсывает пятна еды |
| **Ресничник** | крошечный, много коротких лап, волна Δ_л | самый мелкий размер, где хвост бесполезен |

**Почему не сойдётся к одному:**
1. Нет тела, лучшего по всем трём качествам (скорость, рывок, манёвр). Это следует из формул п. 3, а не из запретов.
2. Законы воды зависят от размера (Re), поэтому мелкие и крупные ищут разные формы.
3. Рот делит еду и жертв по размеру.
4. Вместе с нишами рощ (открытая вода, чаща, пастбище) у каждого типа своё место.

**Честно о рисках:**
- Если одна ниша намного богаче других, она всё равно победит. Физика даёт разнообразию возможность, а удерживает его экология.
- Присоединённая масса на лёгких звеньях может раскачать расчёт. Решение известное: добавлять mₐ к массе звена в знаменателе (полунеявная схема).
- Мозгу нужен третий выход (рывок), и ему придётся заново научиться управлять телом.
- Это **новый геном**: старые существа и миры в этом режиме не загрузятся (только в старом).

## 5. Гены (около 40 на главную ось)

| Группа | Гены | Пределы (для начала) |
|---|---|---|
| размер | яйцо E_я, длина L | по бюджету |
| ширина | W₀, a₁…a₃, b₁…b₃ | a: −0,8…0,8; b: 0…2π |
| членистость | λ | 0,05…0,5 L |
| изгиб в покое | κ₀, κ₁ | −30…30 °/длина |
| конечности | m, χ, θ, ℓ_л, α₀, A_л, Δ_л, σ, f, глубина | m: 0…4; θ: 0…1 |
| ритм | ω, K, Δ, γ, e | ω: 0,02…0,2 |
| размах | A₀, α, p | p: 0,5…8 |
| поворот и рывок | профиль R (3 числа), B | |
| рот | g_рот | 0,3…1,2 |
| окраска | основной цвет, полосы по λ, пятна по a(s) | |
| экология | как сейчас (хищник, голод, болезни, выбор партнёра) | без изменений |

**Скорость счёта.** Тело строится один раз, при рождении (несколько косинусов на звено). Каждый шаг добавляет на звено одну фазу и одну присоединённую массу. Звеньев столько же, сколько сейчас (`MAX_PARTS`). Ожидаемое замедление — десятки процентов, а не разы.

## 6. Как проверить, не строя весь мир

| Этап | Что | Признак успеха |
|---|---|---|
| А. «Гидролоток» | Отдельный инструмент без мира: 10 000 случайных геномов, для каждого замерить скорость хода, цену хода, радиус поворота и разгон за 30 шагов, при трёх размерах | на «фронте лучших» (Парето) **не меньше трёх разных по форме групп**, и при малом и большом размере лучшие формы разные |
| Б. Эволюция в плоском мире, одна еда | режим «Ось», контроль — нынешнее тело, 3 мира | скорее всего тоже одна форма: это контроль, он покажет, что без ниш физика одна не спасает |
| В. Эволюция с рощами | после этапов 0–2 концепции «аммиак и рощи» | число форм держится выше 2–3 на 150 000 шагов |

Этап А — дешёвый и решающий. Если там нет нескольких групп, строить весь режим нет смысла, и это будет видно за один вечер.

## 7. Что взято откуда

- **Курамото, миноги:** цепочки связанных осцилляторов (CPG) — так устроен спинной ритм позвоночных.
- **Грей и Хэнкок (1955):** теория сопротивления для тонких тел (kₙ/kₜ ≈ 2).
- **Лайтхилл (1960–70-е):** удлинённое тело и присоединённая масса.
- **Webb (1984):** сделка «ход — рывок — манёвр» у рыб.
- **Тьюринг (1952):** волна двух веществ даёт полосы и звенья.
- **Клейбер:** обмен ∝ M^¾.
- **Gene Pool 6:** изгиб, накопленный по телу; ветки на ветках; повторение звена (у нас — через λ).
