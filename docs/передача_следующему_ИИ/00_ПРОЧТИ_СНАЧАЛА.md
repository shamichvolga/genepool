## Что это за проект

Gene Pool — мод симуляции Джеффри Вентреллы: 2D-бассейн, в котором плавают «свимботы» (существа из частей тела), едят, спариваются, умирают, а гены мутируют. TypeScript + Vite. Главная цель владельца — **разнообразие форм тел и сосуществование видов**. Пока формы сходятся к одной.

## Главное за один экран

**Сделано в этом чате (подробно — файл 01):**
- сохранение и загрузка всего мира в файл `.gpworld` (точное продолжение, проверено тестом);
- режим отладки: 159 чисел из `Parameters.ts` меняются на ходу, с RU/EN-названиями и пресетами;
- окна панели, отладки, строки состояния и «доминирующих видов» двигаются и растягиваются, положение запоминается;
- окно «доминирующие виды» (мозаика, живой свимбот в каждом куске, правая кнопка: средние гены и уничтожение);
- свой генератор случайных чисел (`gpRandom`, mulberry32 с видимым состоянием);
- мясо и растения делят места (25 % мест под мясо);
- кусок мяса меньше целого рисуется долей точки;
- старт мира тремя кучами по числу частей тела (3–8, 9–12, 13–16);
- хищники видят добычу в 3 раза дальше (`PREDATOR_VISION_SCALE = 3`).

**Вывод из прогонов владельца (файл 01, раздел «Данные»):** на коде `5dba7af` (до этого чата) формы сходятся к одной: на 1 млн шагов главная форма — 6 частей у 96 % существ. Ни одно из сделанных изменений это прямо не решает, нужны ниши (см. файл 04).

**Не проверено и не закончено (подробно — файлы 01 и 04):**
- формулы в режиме отладки — не начаты;
- тест сохранения не перепроверен после двух последних изменений (три кучи и ×3 зрение);
- многосидовый длинный прогон хищников ×3 с контролем — не сделан (это правило проекта, см. `CLAUDE.md`);
