# Карта кода: что где лежит (новое в чате 20–22.10)

Старая карта кода — в `CLAUDE.md`. Здесь только то, что добавлено или сильно изменено.

## Мир и его сохранение

| Файл | Что там | Главные имена |
|---|---|---|
| `src/simulation/Globals.ts` | Свой генератор случайных чисел мира | `gpRandom()` (mulberry32), `rngState`, `setRandomSeed`, `getRandomState`, `setRandomState` |
| `tools/headless.cjs` | Запуск мира без браузера; зерно задаётся через `setRandomSeed(seed)` | `createSimulation(seed, overrides)` |
| `src/simulation/WorldFile.ts` | Формат файла `.gpworld` (магия, JSON-заголовок, чанки на 8 байт, FNV-хеш) | `packWorld`, `unpackWorld`, `hashChunk`, `layoutFingerprint`, `WORLD_FORMAT = 1` |
| `src/simulation/GenePool.ts` | Сохранение и загрузка всего мира | `this.saveWorld(withFamilyTree)`, `this.loadWorld(bytes)`, `this.worldHashes()`, список `WORLD_ARRAYS` (около строки 4780) |
| `src/simulation/SharedState.ts` | Общие массивы мира (в памяти, видимы потокам) | `bots`, `parts`, `mind`, `foodX`, `liveFood` и так далее |
| `src/simhost.worker.ts` | Поток симуляции: сообщения `saveWorld` и `loadWorld`, сжатие gzip через `CompressionStream` | `saveWorld()`, `loadWorld()`, `gzip`, `gunzip` |
| `src/RemotePool.ts` | Сторона страницы: вызовы в поток с ответом | `saveWorldFile`, `loadWorldFile`, `ask()` |
| `src/ui/worldFile.ts` | Кнопки «сохранить мир» и «загрузить мир…»; файл другого размера мира хранится в IndexedDB и загружается после перезагрузки с `?world=N` | `saveWorldToFile`, `chooseWorldFile`, `setupWorldFile` |
| `src/RunRecorder.ts` | После загрузки мира начинается новый прогон в `runs/` | `pool.onWorldLoaded` |
| `tools/save-load-check.cjs` | Проверка точности: сохранить, загрузить в другой мир, сравнить хеши по шагам | — |
| `docs/схема_сохранения_мира.md` | Схема (написана Opus high): состояние, формат, порядок загрузки, 21 подводный камень | — |

Что сохраняется сверх общих массивов: `Swimbot.getPrivateState/setPrivateState` (счётчики, причина смерти), `getPhenotypeOrigins/restorePhenotypeOrder` (порядок частей после автотомии), `Embryology` ставит `part.origin` (`SwimbotTypes.Part`), `Disease.exportStrains/importStrains` (штаммы болезней), `Environment.exportRaw/importRaw` (почва, счётчики растений), `FamilyTree.exportState/importState` (родословная), `ParamStore.changedParams` (изменённые числа).
