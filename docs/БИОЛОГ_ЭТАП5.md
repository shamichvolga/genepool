# Консультация биолога: среда как сила видообразования (этап 5)

Сжатая запись рекомендаций (2026-10-12). Числа получены по замерам прогонов без браузера.

## Замеры
- Уход от места рождения (медиана): 70 ед. за 1000 шагов, 310 за 10 000, 450 за 20 000.
  Дальность расселения за поколение σ ≈ 300–500 ед. Существа почти оседлые.
- Расход энергии ≈ 0.0075/шаг (≈300 за жизнь, ~6 кусков еды).
- Приток еды (классика): 2.5 энергии/шаг на весь мир → ёмкость ≈ 330–420 особей.
- С правильным стартом (сад в центре) «бутылочного горлышка» до десятков нет: популяция
  опускается до ёмкости (~420–500) и держится/растёт (перепроверено на 3 seed).
- В круге зрения (r=300) при плато ≈ 1.8 особи: мир нельзя увеличивать без масштабирования
  численности и еды (иначе не найдут партнёров).
- Время поколения ~10–20 тыс. шагов → 300 тыс. шагов = 15–30 поколений.
- «Соседство» по Райту Nb ≈ 13: структура по расстоянию появится и без среды —
  метрики должны отличать структуру «по среде» от «по расстоянию».

## Обязательные связки (иначе среда — декорация)
1. Компромисс специалист/генералист: широкая толерантность ниже по пику.
2. Среда определяет, какая еда где растёт (ниши).
3. Крупное зерно: биом ≥ 5–10σ (2000–4000 ед.), переход 300–800 ед.
4. Отбор сильнее потока генов: пятна меньше ~2000 ед. «затопляются» мигрантами.
5. Перенос расхождения на спаривание: «волшебный признак» (яркость = камуфляж + сигнал
   для выбора партнёра) и/или выбор места обитания.
6. Гибриды хуже: признаки полигенные (θ = среднее 4 генов), бимодальная среда, выпуклый
   компромисс пищеварения, экологические гены подряд (рекомбинация ломает сочетания у гибридов).
7. Устойчивость во времени: колебания меньше ширины толерантности, дрейф изотерм ≤ 0.01 ед./шаг.

## Формулы и числа по умолчанию
- Мир 16000×16000 (×4 по площади); сетка полей 256×256; сетка растений 64×64 (ячейка 250).
- Численность и приток еды — пропорционально площади (1 кусок / 5 шагов при ×4).
- Температура: T = 0.5 + 0.30·широта(−1..1) + 0.20·смещение биома; 4–6 типов биомов,
  пятна 2500–4000 ед., каждый тип 2–3 раза, сглаживание границ 400–800.
  Сезон: период 10 000 шагов, амплитуда 0.02 (экватор) … 0.08 (полюса).
- g_T = exp(−(T−θ)²/(2w²)); P_T = g_T·(w_min/w)^a, w ∈ [0.04; 0.40], a = 0.5.
- Энергия еды = 50·eff·(0.3 + 0.7·P_T); доп. расход = 0.006·(1 − g_T) за шаг.
- Пищеварение d (0..1): eff_A = 0.15 + 0.85·d^1.5; eff_B = 0.15 + 0.85·(1−d)^1.5.
- Растения: A — оптимум T 0.7, B — 0.3, ширина 0.15 (S = exp(−(T−opt)²/(2·0.15²))).
  70% новых — от родителя на 300–600 ед.; 30% — «дождь семян» с принятием ∝ S_type(T).
  Предел: 6 растений на ячейку 250×250.
- Яркость b и фон B (шаг 2): дальность обнаружения добычи R = 300·(0.35 + 0.65·|b − B|).
- Течения (позже): бездивергентные, ≤ 0.01–0.02 ед./шаг.
- Катастрофы (позже): локальные, раз в ~100 000 шагов, радиус 1500–2500.
- Архипелаг (шаг 2): проливы шириной 300–600, длиной ~1000.

## Гены (отдельный блок 120+)
θ — 4 гена (среднее); w — 2; d — 3; яркость b — 3; разборчивость c — 2; домоседство h — 2;
сила таксиса k — 2; хищность — 2 и голод — 1 (перенести из 51 и 50, которые совпадают с
генами формы тела); нейтральные маркеры — 16 (мутация 0.1–0.2%, шаг ±1–2).
Мутации в блоке: 2% на ген, шаг по Гауссу σ ≈ 9/255, отражение от краёв (без «заворачивания»).
Старые сохранения: копировать ген 51 → хищность, 50 → голод.
Спаривание (шаг 2): согласие партнёра P = exp(−Δb²/(2σ_m²)), σ_m = 0.03 + 0.4·(1−c)².

## Поведение без нейромозга
Комфорт C = P_T × доступность своей еды. Раз в 50 шагов сравнить C с прошлым: хуже → поворот
до 120° с вероятностью 0.6. Если g_T < 0.2 — разворот к лучшему из 4 направлений.
Дом (шаг 2): притяжение к месту рождения за радиусом R_home(h).
Выбор еды: ценность = 50·eff/расстояние; eff < 0.3 игнорировать, пока не голодает.

## Проверка (прогоны без браузера, ≥5 seed, сотни поколений)
Клина θ~T (наклон β, R²); Q_ST ≫ F_ST (по медленным маркерам); частичный тест Мантеля
(генетика ~ среда при учёте расстояния); устойчивые кластеры по (θ, w, b, d) — ≥30 особей,
≥150 тыс. шагов; репродуктивная изоляция, индекс гибридности (два пика = виды);
β-разнообразие; пересадка «свои против чужих».
Контроли: C0 поля выключены; C1 нет компромисса (a=0, линейное пищеварение); C2 случайное
спаривание; C3 мелкое зерно (пятна 100 ед.); C4 без таксиса; C5 проливы против открытого мира.
Для ускорения смены поколений в экспериментах — максимальный возраст 20 000.

## Порядок
Шаг 1: размер мира + масштабирование; температура (широта + биомы); блок генов θ, w, d
(+перенос 50/51) со своими мутациями; формулы P_T и пищеварения; растения A/B по T с дождём
семян; кинез; несколько садов (по одному в биоме, радиус 1200, θ основателей ≈ местной T);
хищники с ~20 000 шага; метрики (клина, кластеры, пересадка) и контроль C0.
Шаг 2: яркость/фон, согласие партнёра и разборчивость, сезоны, дом, архипелаг, остальные метрики.
Шаг 3: течения, катастрофы, дрейф климата, токсины и растение C, эволюция растений, тор.

Ловушки: обрывы среды (ΔT > 3w на расстоянии < σ), слишком дорогая адаптация, мелкое зерно,
большой мир без масштабирования, один сад в большом мире, мутации с заворачиванием,
течения > 0.02, глобальные катастрофы, «вид» только по генам тела.
