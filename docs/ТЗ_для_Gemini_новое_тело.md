# Техническое задание: новые формулы тела, движения и воды для симуляции эволюции Gene Pool

*(Этот текст целиком самодостаточен: в нём всё, что нужно знать о проекте. Отвечай по-русски, простыми словами, но с полной математикой.)*

## 1. Что за проект

**Gene Pool** — симуляция эволюции Джеффри Вентреллы (JJ Ventrella), существует с 1990-х. Автор разрешил некоммерческую доработку. Сейчас это веб-версия на TypeScript.

- Двумерный бассейн, квадрат примерно 8000 × 8000 единиц. В нём до 1500 существ, «свимботов», и до 4000 кусочков еды.
- Каждое существо — дерево из **не больше 16 жёстких звеньев** (палочек с длиной и шириной), которые машут в воде и этим толкают тело.
- **Геном** — 256 байт (числа 0…255). Примерно 116 первых генов строят тело и задают движение, гены 120–170 — экология (хищник или травоядный, голод, выбор партнёра, болезни и т. д.), остальные пока свободны.
- Размножение половое: партнёры скрещивают геномы, есть мутации. Отбора «сверху» нет: выживает тот, кто ест и успевает размножиться.
- У существа есть **нейросеть** (30 входов, 6 скрытых, 12 выходов). Она решает, к какой цели плыть (еда, партнёр, бегство, охота) и с каким усилием. Как тело при этом машет — решает не мозг, а гены тела (см. п. 3).
- Еда: растения (рассыпаны по бассейну, появляются заново) и мясо (трупы). Есть хищники, болезни толпы, течения.
- Физика считается в параллельных потоках (Web Workers) по плоским массивам. Каждый шаг для каждого существа проходит по всем его звеньям, поэтому **формулы должны быть дешёвыми**: O(число звеньев) на шаг. Тело строится один раз при рождении, там можно считать сложнее.

## 2. Проблема

В любом запуске за 60–150 тысяч шагов **все существа приходят к одной форме: мелкий червяк из 5–6 звеньев.** Новых видов не появляется. Владелец считает это провалом: главная цель проекта — **разнообразие форм и сосуществование видов**.

Что уже пробовали (всё это не сломало монополию):
- болезни, которые сильнее бьют по густой толпе одной формы;
- стартовые кучи существ разного размера;
- хищникам втрое большая дальность зрения;
- растения, которые растут, и «сила укуса», зависящая от массы (крупный ест большие растения);
- течения воды и умение их чувствовать.

Наша гипотеза: работает принцип конкурентного исключения. Ресурс по сути один, и **физика тела даёт одно лучшее тело для всех задач и всех размеров**. Отдельно разрабатывается экология с несколькими нишами (лес из деревьев-стен, открытая вода и т. п.). **Твоя задача — физика и строение тела.**

Ещё одно наблюдение владельца: существа будто «скользят по инерции», вода кажется недостаточно плотной.

## 3. Как устроено сейчас (точные формулы из кода)

### 3.1. Ген → значение

```
нормированный ген n = ген / 256        (0…1)
значение = MIN + (MAX − MIN) · n
```

Пределы: длина звена 3…27, ширина 0,5…7, частота 0,02…0,2 (радиан за шаг), размах взмаха −60…+60°, фаза −1…+1, угол ветки −90…+90°.

### 3.2. Строение тела (эмбриология)

Есть 4 «категории» звеньев. У каждой по 28 генов: цвет начала и конца, ширина начала и конца, длина начала и конца, размах и фаза взмаха, размах и фаза поворота, то же для веток, число звеньев подряд (1…5), период ветвления (1…4), угол ветки, число веток (1…3), сдвиг ветвления, категория ветки, отражение, сглаженность. Общие гены: частота (одна на тело) и «cutoff» (сколько звеньев всего, 2…15).

Тело растёт так (упрощённо, код TypeScript):

```ts
// цепочка из sequenceCount звеньев категории c, от родителя parent под углом branchAngle
function generateBodySequence(parent, branchAngle, c, reflect) {
  for (let i = 0; i < cat[c].sequenceCount; i++) {
    if (partIndex >= cutOff) return;
    partIndex++;
    const part = parts[partIndex];
    if (i === 0) {                         // первое звено цепочки — ответвление
      part.parent = parent; part.angle = branchAngle;
      part.amp = cat[c].branchAmp;  part.phase = cat[c].branchPhase * partIndex;
      part.turnAmp = cat[c].branchTurnAmp; part.turnPhase = cat[c].branchTurnPhase * partIndex;
    } else {
      part.parent = partIndex - 1; part.angle = 0;
      part.amp = cat[c].amp;  part.phase = cat[c].phase * partIndex;
      part.turnAmp = cat[c].turnAmp; part.turnPhase = cat[c].turnPhase;
    }
    part.amp *= reflect;
    const f = cat[c].sequenceCount > 1 ? i / (cat[c].sequenceCount - 1) : 0;
    part.width  = cat[c].startWidth  + f * (cat[c].endWidth  - cat[c].startWidth);
    part.length = cat[c].startLength + f * (cat[c].endLength - cat[c].startLength);
    // каждое branchPeriod-е звено пускает ветки категории cat[c].branchCategory
    if ((i + cat[c].branchShift) % cat[c].branchPeriod === 0) markForBranching(partIndex);
  }
}
// старт: generateBodySequence(root, 0, категория 0, 1); потом ветки, пока есть отмеченные
// веток branchNumber штук, веером: угол = branchAngle * (−1 + 2b/(branchNumber−1)), часть отражена
масса звена = длина × ширина;   масса тела = сумма
```

### 3.3. Движение (каждый шаг, для каждого звена p ≥ 2)

```ts
timer += timerDelta * effort;      // effort — выход мозга; timerDelta падает при голоде и старости
d = направление_на_цель · перпендикуляр_к_курсу;  // −1 (цель слева) … +1 (справа)
изгиб_p = (amp_p + turnAmp_p · d) · sin( timer · frequency + phase_p + turnPhase_p · d );
угол_p  = угол_родителя + angle_p + изгиб_p;
// позиции звеньев: от корня по цепочке, потом всё тело сдвигается, чтобы центр масс остался на месте
```

### 3.4. Вода и толчок (каждый шаг)

```ts
for (p of parts) {
  v = середина_p(сейчас) − середина_p(прошлый шаг);   // скорость звена относительно воды
  n = перпендикуляр к звену (единичный);
  stroke = (v · n) * length_p / sumLengths;
  force  = n * stroke;
  energy -= |stroke| * 0.01;                           // цена плавания
  velocity     += −force;                              // ВНИМАНИЕ: без деления на массу
  torque       −= (force · перпендикуляр_от_центра_к_звену) / sumLengths;
}
spin += torque;   position += velocity;   angle += spin;
energy −= 0.0001 + базальный_обмен;
```

Важно:
- Сопротивление есть **только поперёк звена**. Вдоль звена вода не тормозит, отсюда скольжение.
- Сила **не делится на массу**: крупное тело разгоняется так же легко, как мелкое.
- Вода **одна и та же для любого размера**.

### 3.5. Гены из старой версии для ПК (Gene Pool 6, 2008)

Исходников нет, известны только названия генов, которых нет в веб-версии: *replicate number, replicate delay, secondary branching, growth turn amp, growth turn phase, growth turn phase acc, thick growth, length growth, branch amp flip, color shift scale, root size, category shift, continuation, end outline*. По названиям — повторение сегментов, ветки на ветках, изгиб, накапливающийся вдоль тела, рост толщины и длины по цепочке. Можешь использовать как вдохновение.

## 4. Правила, которые нельзя нарушать

1. **Никаких костылей.** Нельзя «запретить» форму, ввести штраф за популярную форму, множитель «чтобы работало» или искусственный предел. Только естественные законы (физика, химия, экология), из которых разнообразие выходит само.
2. **Дёшево каждый шаг:** O(число звеньев), не больше 16 звеньев. Тело строится при рождении, там можно дороже.
3. Двумерный мир (вид сверху).
4. Геном — массив байт (до 256). Мутация меняет байт. Желательно, чтобы маленькая мутация давала маленькое изменение тела.
5. Мозг уже умеет выдавать: направление к цели (d от −1 до +1), усилие (0…1). Можно предложить 1–2 новых выхода мозга.
