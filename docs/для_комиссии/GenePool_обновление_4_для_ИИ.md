## 2. Что сделано

### 2.1. Растения с генами (`PLANT_EVOLUTION_ENABLED`, включено)
- **Ген «скорость взросления» g (0..1):**
  - взрослое в возрасте 16 000 − 12 000·g шагов (быстрые — 4 000, медленные — 16 000; раньше все — 1 500);
  - старое — в 2,5 раза позже, гниёт — в 4 раза позже;
  - энергия старого: 1 + 0,4·(1 − g), то есть богаты только медленные.
- **Ген «дальность семян» s:** семя падает на 40 + 1460·s² (×0,5…1,5).
- **Семена дают только взрослые растения** (до 8 попыток найти взрослое, иначе любое). Мутация ±0,05.
- **Росток растёт:** энергия от 0,35 до 1 к взрослению.
- **Замер, 40 000 шагов** («сытность» запаса — средняя энергия растения для среднего едока):

  | | ростки / взрослые / старые | сытность |
  |---|---|---|
  | классика без стадий | 0 / 100 / 0 % | 1,00 |
  | прежние стадии | 14 / 39 / 47 % | 1,10–1,20 |
  | с генами | 37 / 39 / 24 % | 0,75–0,80 |

- **Ожидание:** при сильном выедании растут «быстрые», при слабом — «медленные»; дальность семян — компромисс между зарослями и рассеиванием. Ген «растений» сам по себе не говорит, что лучше.

### 2.2. Механики для конечностей (выключены, проверяются)
- **«Сито» (`FILTER_FEEDING_ENABLED`):** любая часть тела, кроме несущей рот, задевшая **росток** (до взросления), съедает его с эффективностью 0,6. Проверка каждые 4 шага. Взрослые и старые растения — только ртом.
  - Замер: около 10 % растений съедается «ситом».
- **«Шипы» (`LIMB_SPINES_ENABLED`):** успех укуса × max(0,4; 1 − 0,1·(кончики − 2)), где кончик — часть, из которой ничего не растёт. Сейчас в среднем 3 кончика на тело.
- Обе механики не бонус «за число частей»: конечность что-то делает, а платит взмахами.
