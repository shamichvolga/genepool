# Памятка для ИИ, который продолжает работу над GenePool

Этот файл Claude Code читает сам при старте каждого нового чата в этой папке. Держите его коротким и свежим: в конце большой работы обновите раздел «Где остановились».

## Кто и что
- Владелец: @Lionsmane96 (t.me/Lionsmane96). Пишет по-русски, отвечать по-русски, простыми словами.
- Проект: мод Gene Pool Джеффри Вентреллы — симуляция эволюции «свимботов». TypeScript + Vite.
- Главная цель: **разнообразие форм тел**, сосуществование видов.

## Правила работы (обязательно)
1. **Никаких костылей.** Только естественные, экологические механизмы: законы природы вместо ограничителей и множителей «чтобы работало».
2. **Коммит после каждого шага.** В конце сообщения строка `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
3. **Каждый ответ заканчивать таблицей** «задача | идея | модель ИИ» — что дальше и какой моделью это делать.
4. **Каждая серия экспериментов — со своим контролем из того же коммита.** Любой новый ген сдвигает случайные числа, поэтому сравнивать со старыми прогонами нельзя.
5. **Прогоны при проверке — короткие**, а пользователь не любит долго ждать.
6. **Идеи 8–27** из `docs/идеи_сосуществования.md` делать только по команде пользователя.
7. Не перезапускать вкладку пользователя. `Запустить GenePool.bat` (dev-сервер, порт 5173) применяет правки кода через плашку. Для своих проверок есть отдельный сервер `genepool-dev2` (порт 5199) в `.claude/launch.json`.

## Карта кода
- **Параметры и выключатели:** `src/simulation/Parameters.ts`. Почти каждая механика — флаг `..._ENABLED`, его можно выключить в эксперименте.
- **Симуляция:** в веб-воркере `src/simhost.worker.ts`, параллельные ядра — в `src/parallel`.
  - `src/simulation/PerceptionKernel.ts` — что видит (добыча, хищники, партнёры);
  - `src/simulation/DecisionKernel.ts` — что решает (еда, укус, каннибализм);
  - `src/simulation/PhysicsKernel.ts` — движение, рост, траты энергии;
  - `src/simulation/Swimbot.ts`, `src/simulation/GenePool.ts` — свимботы и мир.
- **Новые механики (октябрь 2026):** `src/simulation/Disease.ts` — болезни; `src/simulation/Kin.ts` — родню не едят; `src/simulation/EcologyGenes.ts` — номера экологических генов; `src/simulation/MindLayout.ts` — ячейки памяти мозга.
- **Интерфейс:** `index.html`, `css/panel.css`, `src/ui/`.
  - `src/ui/ui.ts` — кнопки;
  - `src/ui/lang.ts` — русский язык и подсказки «?»;
  - `src/ui/graph.ts` — график;
  - `src/ui/panelTexts.ts` — карточка свимбота;
  - `src/ui/userSwimbots.ts` — свимботы пользователя.
  - `src/ui/layout.ts` — окна, которые двигают и растягивают (панель за шапку, плашка внизу, отладка); положение помнится в localStorage;
  - `src/ui/debug.ts` — режим отладки (кнопка с гаечным ключом): окошки со всеми числами из `Parameters.ts`, ✔ применить, отмена, по умолчанию, пресеты (числа + расположение окон);
  - `src/ui/worldFile.ts` — кнопки «сохранить мир / загрузить мир»; `GenePool.saveWorld/loadWorld` (в `GenePool.ts`), формат файла в `src/simulation/WorldFile.ts`, схема в `docs/схема_сохранения_мира.md`. Проверка точности: `node tools/save-load-check.cjs --seed 1 --warm 3000 --after 400` (сохранил → загрузил в другой мир → хеши всех массивов совпали). Глобальный ГСЧ — `gpRandom` в `Globals.ts` (mulberry32, состояние читается и задаётся);
  - `src/ui/species.ts` — окно «доминирующие виды» (мозаика по долям, живой свимбот в куске, правая кнопка: средние гены / уничтожить вид); вид = группа свимботов с близкими генами (<12 %, как «генетические кластеры»), счёт в `GenePool.getSpeciesView`, номера видов держатся между пересчётами;
  - `src/simulation/ParamStore.ts` — как новые числа доходят до воркеров (плагин `liveParameters` в `vite.config.ts` делает константы изменяемыми). Числа, вычисленные из других (например `MIN_MAXIMUM_AGE`), в списке не участвуют.

## Эксперименты без браузера
- Один прогон: `node tools/form-census.cjs --seed 1 --steps 60000 --every 5000 --out tools/results/имя --set "ФЛАГ=значение"`.
  - `--set` подменяет константы из `src/simulation/Parameters.ts`.
- Сравнение: `node tools/experiment-compare.cjs tools/results --prefix имя- --at 30000`.
  - показывает население, хищников, эффективное число форм и долю главной формы.
- Хищники по размеру тела: `node tools/predator-by-size.cjs tools/results --prefix имя-`.
- Пример серии с контролем: `tools/run-d19.sh`. Один прогон на 60 000 шагов идёт около часа.

**Главный вывод d20:** «хорошее разнообразие» прошлых прогонов (d9–d10) было разнообразием стартовой случайной популяции до начала отбора, а не устойчивым сосуществованием. При конкуренции за одну еду побеждает одно дешёвое тело на 4–5 частей (конкурентное исключение). Нужны **ниши** — компромиссы, где разные тела лучше в разном.

**Незаконченные дела (по приоритету, начинать только с согласия пользователя):**
1. **Ниши для форм:** разная еда для больших и малых тел (сейчас `PLANT_STAGES` почти не работает), типы частей тела (идея 26), разные места в среде. Мерить на 100 000+ шагов с контролем.
2. **Крупные хищники голодают** (98 % от голода, только треть хищников ловит кого-либо). Предложено: удельная цена движения падает с массой, как в природе. Не одобрено.
3. **Качели численности** 250–6000 (перевыпас). Варианты: логистический рост растений в клетке, укрытия.
4. **Перевести страницы вкладки «инфо»** (`src/ui/info.ts`, 28 страниц) на русский через `src/ui/lang.ts`.
5. Идеи 8–27 из `docs/идеи_сосуществования.md` и идея 17 (метаморфоз) — только по команде.
6. Когда пользователь сделает долгий прогон в браузере — прочитать его `runs/*/REPORT.md`.
